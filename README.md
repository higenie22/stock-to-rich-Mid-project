# S&P 500 안정성 분류·수익성 검증 프로젝트

## 프로젝트 개요

S&P 500 종목을 변동성과 시장 민감도로 분류하고, Stable 후보군 안에서 미래 상대수익 순위를 예측해 Top-10을 추천하는 연구 프로젝트입니다. `sp500_stability_v17.ipynb`와 `test_validation_report.ipynb`의 가설·실험을 하나의 실행 구조로 모듈화했습니다.

분석 데이터와 피처의 기준은 `test_validation_report`로 통일하고, Stable 정의는 v17의 해석 가능한 정책을 사용합니다. 최종 추천은 OOS 성과로 모델 비중을 고르지 않고, 2020~2022 Purged CV의 모델별 IC로 산출한 ReLU 비중을 고정해 생성합니다.

> 이 프로젝트는 연구·검증용입니다. 추천 점수는 기대수익률이나 상승확률이 아니며 투자 자문을 의미하지 않습니다.

## 연구 흐름

```
저장된 가격·시장·구성종목·섹터·거시 데이터
  → 시점 기준 피처 생성 및 구성종목 이력 적용
  → 날짜별 Vol(120d) + |Beta(120d)| K-Means 분류
  → Stable 후보군 생성
  → 기간·피처·학습방식·거시·LSTM 가설 검증
  → 2020~2022 Purged CV에서 4개 모델의 평균 IC 산출
  → 양수 IC만 ReLU 정규화해 앙상블 비중 고정
  → 2024-07 이후 동일 4개 OOS 구간 평가
  → 최신 시점 Stable Top-10 및 종목별 수치 설명 저장
```

최종 앙상블의 구성 모델은 ElasticNet, MLP, Macro-LightGBM, LSTM입니다. 각 모델의 원 예측값을 그대로 더하지 않고, 같은 날짜 후보군에서 계산한 백분위 순위를 CV ReLU 비중으로 합산합니다.



## 주요 가설과 실험

| 번호 | 가설·연구 질문                                          | 실험 방법                                                    | 해석 범위                                                    |
| ---: | ------------------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
|   H1 | 변동성과 시장 민감도는 서로 보완적인 안정성 위험축인가  | `Vol(120d)` 단독, `|Beta(120d)|` 단독, 두 축 K-Means의 Stable 오분류율과 미래 MDD 비교 | 두 축의 상관성과 분류 결과를 함께 확인. 결합 모형이 모든 지표에서 단독축보다 우월하다고 전제하지 않음 |
|   H2 | 안정성 판단의 Lookback은 120일이 적절한가               | 20·30·60·120·252일별 미래 Risky 오분류율과 미래 MDD 비교     | 252일은 피처 성숙 때문에 평가시점 수가 달라 직접 최적성 비교에 제약 |
|   H3 | 안정성 군집수 K=3이 적절한가                            | K=2~6의 Silhouette, Davies-Bouldin 지수와 최소 군집 비중 비교 | 통계적 분리도와 Stable/Middle/Risky의 해석 가능성을 구분     |
|   H4 | Stable 군은 이후에도 Risky 군보다 안정적인가            | 20개 장기 평가시점에서 군별 미래 120일 변동성, MDD, -15% 낙폭 비율, 미래 Risky 비율 비교 | 미래 성과를 군집 생성에 사용하지 않고 사후 검증에만 사용     |
|   H5 | Stable 분류와 추천에 섹터 편향이 존재하는가             | 섹터별 Stable 비율, 글로벌·산업별 정책 비교와 블록 부트스트랩 수행 | 정적 섹터 매핑의 한계가 있으며 최종 Top-10에는 섹터 50% 상한 적용 |
|   H6 | Momentum(120d)과 RSI(56d)가 서로 다른 종목을 선별하는가 | 두 변수를 BASE 피처에 포함해 결합 모델 평가                  | 현재 모듈에는 단독·결합을 완전히 분리한 ablation이 없어 개별 효과를 확증하지 않음 |
|   H7 | 추가 피처가 기본 피처보다 선별력을 높이는가             | BASE 대비 차분·거래량 피처를 2020~2022 Purged CV와 동일 OOS 표본에서 비교 | CV 결과와 OOS 탐색 결과를 분리해서 해석                      |
|   H8 | 학습 방식과 모델 구조가 순위 일반화를 개선하는가        | Expanding/최근 3년 학습, LightGBM·Ranker·ElasticNet·MLP, 타깃 정의를 공통 표본에서 비교 | 고정 하이퍼파라미터 실험이며 전체 구조를 nested CV로 고른 것은 아님 |
|   H9 | 시퀀스 구조가 같은 종점의 표형 모델보다 유효한가        | 20거래일 시퀀스를 사용하는 LSTM과 동일 예측 종점 LightGBM 비교, 내부 Validation으로 epoch 선택 | H8과 내용이 겹치므로 독립적인 성공 가설로 중복 집계하지 않음 |
|  H10 | 성과가 기존 요인과 독립적인 알파인가                    | 모멘텀·베타 통제 전후 IC, 시장 대비 성과, CAPM·다요인 알파와 신뢰구간 진단 | 신뢰구간과 표본 수를 함께 보고 기술적 관찰과 통계적 확증을 구분 |



## 추가 모델링 실험

- **투자기간 비교:** 20·60·120거래일별 IC, 기간수익, 누적수익과 MDD를 같은 시작 원칙으로 비교했습니다.
- **타깃 비교:** 시장 대비 초과수익, 절대수익, 미래가격 타깃을 같은 후보군과 평가수익으로 비교했습니다.
- **학습 범위 비교:** 전체 과거를 누적하는 expanding 학습과 최근 3년 rolling 학습을 비교했습니다.
- **Base 모델 비교**: 같은 Tree기반의 모델인 LightGBM, XGBoost, CatBoost 모델의 테스트셋 성능을 비교했습니다. 수익성에 대한 예측은 미세한 차이로 CatBoost > XGBoost > LightGBM 이었지만, 추천 종목들의 최대 낙폭들에 대해서 LightGBM >> XGBoost >> CatBoost 였기에, 안정성 측면에서 유의미한 차이가 있는 LightGBM 모델을 Base 모델로 선정했습니다.
- **모델 비교:** Base-LightGBM, LightGBMRanker, ElasticNet, MLP, Macro-LightGBM, LSTM의 횡단면 IC와 Top-10 경로를 확인했습니다.
- **거시 피처 비교:** 미시 피처만 사용한 모델, 거시 피처 추가 모델, 거시·미시 상호작용 모델을 동일 OOS 날짜에서 비교했습니다.
- **강건성 점검:** 후보 coverage, 섹터 집중도, 소수 종목 수익 기여, 블록 단위 결과와 미정산 -50% 민감도 시나리오를 기록했습니다.
- **앙상블 비교:** 단독 모델과 여러 고정 비중 후보를 공통 OOS 구간에서 비교하되, 최신 추천 비중은 OOS 결과가 아니라 CV 평균 IC만으로 확정했습니다.

현재 저장된 실행 결과에서 관찰된 대표 결과는 다음과 같습니다. 수치는 새 데이터와 코드로 재실행하면 달라질 수 있습니다.

- Stable 군의 미래 평균 변동성은 약 24.6%, 평균 MDD는 약 -15.4%였고 Risky 군은 각각 약 47.3%, -28.1%로 관찰됐습니다.
- 동일한 20개 평가시점을 가진 20·30·60·120일 중 120일의 미래 Risky 오분류율이 약 12.8%로 가장 낮았습니다. 252일은 약 10.8%였지만 평가시점이 18개로 적었습니다.
- K=2의 평균 Silhouette가 K=3보다 높았습니다. K=3은 순수한 통계적 최적값이라기보다 Stable/Middle/Risky 3단계 해석과 군집 규모를 함께 고려한 정책입니다.
- 변동성 단독 정책의 평균 오분류율이 두 축 K-Means보다 낮게 나타나, H1의 결합 우월성은 단순 확증되지 않았습니다. 두 축 결합은 변동성과 시장 민감도를 함께 반영한다는 다면적 위험 정의에 의미가 있습니다.
- CV ReLU 비중 예시에서는 ElasticNet 약 33.3%, MLP 약 64.3%, Macro-LightGBM 0%, LSTM 약 2.4%가 산출됐습니다. 이는 OOS 수익률이 아니라 2020~2022 평균 CV IC로 계산한 값입니다.
- 해당 CV 고정 앙상블의 4개 OOS 연결 결과는 누적 약 16.9%, MDD 약 -11.3%였습니다. 4개 중 1개 기간에는 미정산 -50% 가정 종목이 포함돼 있으며, 평균 Fold IC가 약 0.0098로 낮고 부호도 일관되지 않아 일반화된 알파로 해석하지 않습니다.

| Fold | 신호일     | 진입일     | 청산일     |
| ---: | ---------- | ---------- | ---------- |
|    1 | 2024-07-01 | 2024-07-02 | 2024-12-20 |
|    2 | 2024-12-19 | 2024-12-20 | 2025-06-17 |
|    3 | 2025-06-16 | 2025-06-17 | 2025-12-08 |
|    4 | 2025-12-05 | 2025-12-08 | 2026-06-02 |

전체 연구 단계가 같은 CV를 공유하는 것은 아닙니다. 기본·차분·거래량 피처 비교, 예측 방향, 최종 4모델 비중은 2020~2022 CV를 사용합니다. K·Lookback 장기 검증, 투자기간 비교, 개별 모델 구조 실험과 LSTM 내부 검증은 각각 별도의 검증 경로를 가집니다.

## 데이터 누수 방지와 재현성

- 피처는 각 신호일 현재 또는 이전 정보로 계산합니다.
- 수익 라벨은 신호 다음 거래일부터 120거래일 후까지의 가격으로 생성합니다.
- 학습 행은 `target_end < fold_start`와 `label_available_at < fold_start`를 만족해야 합니다.
- 최종 가중치는 2020~2022 CV 결과에서 한 번 산출하고 OOS 동안 고정합니다.
- OOS Fold에서는 해당 신호일까지 확정된 라벨만 추가해 모델을 다시 학습합니다.
- 입력 파일 SHA-256과 실행 환경을 `manifest.json`에 저장합니다.
- 모든 CV 평균 IC가 0 이하이거나 필요한 모델 IC가 유효하지 않으면 추천을 보류합니다. 임의로 균등 비중을 사용하지 않습니다.

날짜별 Stable 분류는 해당 날짜의 횡단면 위험 피처만 사용합니다. 미래 120일 위험은 분류를 만든 뒤 가설을 평가할 때 사용합니다. `stability.py`의 별도 미래 위험 지도학습 진단은 최종 Stable 생성기나 수익 추천모델로 사용하지 않습니다.

## 결과 해석과 한계

- 최종 ReLU 비중 산정에는 OOS 수익률과 MDD를 사용하지 않지만, OOS 구간에서 여러 연구 가설과 구조를 반복 관찰한 데 따른 연구 수준의 선택편향은 남을 수 있습니다.
- OOS 120일 리밸런싱 표본은 4회이므로 횡단면 관측치가 많더라도 독립적인 시계열 표본이 충분하다고 볼 수 없습니다.
- 2024~2026년 OOS는 특정 시장 국면에 제한되므로 다른 약세장과 위기 국면으로 일반화하려면 추가 평가가 필요합니다.
- 구성종목 이력을 적용하지만 상장폐지·합병·티커 변경 및 과거 재무 정보까지 포함한 완전한 point-in-time 유니버스를 보장하지 않습니다.
- 미정산 종목 -50%는 보수적 민감도 가정이며 실제 체결 수익이 아닙니다.
- 수수료, 세금, 시장충격과 슬리피지는 성과에 반영하지 않았습니다.
- 종목 가격과 벤치마크의 배당·기업행동 반영 기준이 다르면 상대수익 비교가 왜곡될 수 있습니다.
- 정적 섹터 매핑과 단일 섹터 50% 상한은 시점별 산업분류 변화와 최적 제약을 보장하지 않습니다.
- 거시지표와 기업 재무제표 등 외부 요인은 제한적으로만 반영합니다.
- 동일가중 Top-10은 실험 기준점이며 위험기여도 기반 비중 최적화는 포함하지 않습니다.

발표나 보고서에서는 “Stable 후보군 내부의 OOS 선별 성과가 관찰되었다”고 설명하는 것이 적절합니다. 장기간과 다양한 시장 국면에서 같은 성능이 반복되기 전에는 안정적인 알파나 일반화된 우월성을 보증하지 않습니다.
